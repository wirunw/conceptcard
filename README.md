# Challenge to Concept Card

หน้าเว็บเวิร์กช็อปที่ใช้ AI ช่วยคิดทีละขั้น จากปัญหาด้านสุขภาพไปจนได้ Concept Card ของผลิตภัณฑ์หรือบริการ แต่ละขั้นทำซ้ำแบบเดียวกัน คือกรอกสั้น ๆ คัดลอก prompt ไปวางใน AI ที่ใช้ แล้ววางคำตอบที่เลือกกลับมา คำตอบของขั้นก่อนจะถูกส่งต่อไปใน prompt ขั้นถัดไปเอง

ทั้งหมดมี 7 ขั้น ได้แก่ หาโจทย์ · เข้าใจคน · ตั้งคำถาม · ระดมไอเดีย · คัดและตรวจ · Concept Card · Pitch

## วิธีใช้

เปิด `index.html` ในเบราว์เซอร์ได้เลย หรือเปิด GitHub Pages ของ repo นี้ (Settings → Pages → Deploy from branch → `main` / root)

- **ดูตัวอย่าง:** กรณีสมมติของพลอย อ่านได้อย่างเดียว กด "แก้ต่อจากตัวอย่างนี้" เพื่อคัดลอกไปแก้เองได้
- **เริ่มเรื่องของฉัน:** กรอกเรื่องของตัวเองตั้งแต่ต้น
- **Prompt:** สลับได้ทั้งภาษาไทยและภาษาอังกฤษ
- **ส่งออกผลลัพธ์:** ปุ่ม "ส่งออกผลลัพธ์" ด้านบน หรือขั้น 7 ดาวน์โหลดเป็น .txt หรือ .md หรือคัดลอกทั้งหมด (Concept Card, pitch, สิ่งที่เลือกไว้ทุกขั้น และ AI log)
- **ส่วนท้ายหน้า:** มีแนวทางใช้ AI อย่างปลอดภัย และแผนการสอนสำหรับผู้สอน

## ข้อมูลและความเป็นส่วนตัว

ข้อมูลที่กรอกเก็บไว้ใน `localStorage` ของเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่ได้ส่งไปเซิร์ฟเวอร์ใด เปลี่ยนเครื่องแล้วข้อมูลจะไม่ตามไปด้วย ห้ามใส่สูตรจริง ข้อมูลที่ยังไม่เผยแพร่ ข้อมูลผู้ป่วยที่ระบุตัวตนได้ หรือเอกสารลับของพันธมิตรลงใน AI สาธารณะ

## โครงสร้างไฟล์

- `index.html` — หน้าเว็บทั้งหมดในไฟล์เดียว (HTML/CSS/JS ฝังรูปไว้ในไฟล์แล้ว)
- `assets/` — สำเนาโลโก้คณะและ mascot (อ.หมี) ที่ตัดพื้นหลังแล้ว
